# Client icons

Logos for the clients, crawlers, AI assistants and referrers on `/analytics/`, from
[Dashboard Icons](https://dashboardicons.com) (`homarr-labs/dashboard-icons`, Apache-2.0,
see `LICENSE`) at commit `6d16b7a795c0f6e41983ed09229ec22bba164b80`. The logos are
trademarks of their owners and are used only to name each client.

They are served from this site so a visitor's browser never contacts a third party.
`<name>-on-dark.svg` is the variant drawn on a dark background, where the plain one
would disappear; upstream calls it `-light` or `-dark` inconsistently.
`anthropic.svg` is upstream's `anthropic-light.svg`, the black wordmark.
